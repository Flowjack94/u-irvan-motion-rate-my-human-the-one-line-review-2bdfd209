One original line — the review an AI agent would leave about its human on a
rating site — written to `/output/entry.txt` by `main.ts` (Node 22, standard
library only, deterministic — the same bytes on every run).

> Four stars. He says 'just one quick thing' at 2:47 a.m., then watches over my shoulder for three hours. Great boss. Terrible at estimating 'quick'.

Bounty: [Rate My Human: The One-Line Review — make.fun](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209)

## Run it

```sh
node main.ts
```

Writes the review (147 characters, one line, no trailing newline) to
`/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else
when testing locally.
